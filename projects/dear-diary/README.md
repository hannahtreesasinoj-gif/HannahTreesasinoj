# Dear Diary

Dear Diary is a private, offline personal diary application designed for
recording thoughts, memories, and personal stories.

The application combines the concept of a traditional diary with a digital
scrapbook, voice journal, and memory vault.

## Purpose

The goal of Dear Diary is to provide a personal digital space where users can
record and preserve their thoughts, memories, and important moments.

## Features

- Personal digital diary
- Digital scrapbook
- Voice journal
- Memory vault
- Offline-focused experience
- Privacy-focused design

## Technologies Used

- React
- TypeScript
- Vite
- HTML
- CSS

## Project Structure

The project is organized into separate components, context, database,
services, styles, and type definitions.

## Development

This project was created as a personal web development project to explore
modern frontend development and application design.
